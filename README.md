## 🛠️ 사용 기술
- Node 24.11.0
- next 16.1.6
- react 19.2.3
- tailwindcss 4
- typescript 5
- eslint 9

## 🚀 빌드 및 실행
1. 저장소 클론  
```bash
git clone https://github.com/DXers-edu/tarot-reading-web.git
cd tarot-reading-web
```

2. 애플리케이션 실행  
```bash
npm run dev
```
